## Decisions made (D11 decided)
- **D11 (Decided):** Reference Workflow "Doctor Emergency Leave" (Blueprint §14 M4 Milestone Demo). The autonomous runtime implements tiered action boundaries: T1 slot cancellations and rebooking slot searches execute autonomously; T2 refunds execute autonomously only up to the principal's explicit mandate limit (`perActionLimit` and `dailyLimit`); T3 refunds exceeding mandate limits park deterministically at a `human_gate`, escalating a priority item into the Attention Center with branch-level role routing (`billing_manager`). Resumption preserves state integrity, issues cryptographically signed Ed25519 proof receipts for every action in the chain, and dispatches an asynchronous verification job for settlement reconciliation.
