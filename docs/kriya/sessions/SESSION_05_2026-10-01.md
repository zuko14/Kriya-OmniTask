## Known limit, stated plainly
If the process dies after the external system acted but before the side-effect ledger row is
written, the node runs again with the same idempotency key. Exactly-once therefore depends on the
target system honouring that key. The Tool Gateway contract (WP-3.6) must require it, and the
payment and WhatsApp connectors must pass it through.
