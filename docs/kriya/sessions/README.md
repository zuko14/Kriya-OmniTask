# Session Records

One file per working session: `SESSION_NN_YYYY-MM-DD.md`. Written by whichever agent did the
work (Claude Code, Antigravity, …) **before the session ends**. `00_STATUS.md` keeps the short
summary; the session file keeps the detail the next agent needs to continue without re-deriving it.

## Template (copy for each new session)

```markdown
# Session NN — YYYY-MM-DD — <agent name/model>

## Goal
Which WPs from 03_IMPLEMENTATION_PLAN.md this session targeted.

## Baseline (before any change)
- tsc: …   - vitest: N passed / N failed / N skipped

## What changed (file by file)
| File | Change | Why (audit item / WP) |
|---|---|---|

## Verification (evidence)
Commands run and their results (tsc, vitest counts, any live tests).

## Status changes
| WP | Before → After | Evidence |
|---|---|---|

## Found during the session (not fixed)
New problems with file:line; also added to 01_CURRENT_STATE_AUDIT.md.

## Decisions made / needed

## Next session should start with
Exact WP + first concrete step.
```

Exact test counts: `npx vitest run --reporter=json --outputFile=<tmp>/vt.json`, then read
`numPassedTests`, `numFailedTests`, `numPendingTests` (the default reporter's colour codes break grep).
