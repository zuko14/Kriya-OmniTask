# Session 10 — 2026-10-02

## Goal
Implement WP-4.5: Document (Lens) agent with deterministic parsers (L0), model extraction cascade (L2/L3), strict zero-retention (process in memory, store structured output + hashes only), and fail-closed human escalation on low confidence (< 0.75), adhering to the core principle: "Verified action. AI that acts, and proves it acted right."

## Decisions made (D10 decided)
- **D10 (Decided):** ADR-013 on Zero-Retention Document Extraction & Cost-Cascade Architecture. Raw document bytes and text are never written to disk or database; only the SHA-256 hash and schema-validated structured fields are persisted. High-confidence deterministic parsers (L0) run first at 0 model cost. Low-confidence extractions (< 0.75) or schema mismatches fail closed directly into the Attention Center queue (`reason_category: 'low_confidence'`).
