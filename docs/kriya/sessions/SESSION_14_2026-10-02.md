## Decisions made / needed

- **D14 decided (ADR-017: Durable Job Queue, Worker Lease & Quiet Hours Governance Architecture):**
  - PostgreSQL `SELECT ... FOR UPDATE SKIP LOCKED` (sanitized cleanly in SQLite in-memory test environments) guarantees zero-collision atomic job claiming across horizontally scaled worker instances.
  - Multi-queue worker polling generates dynamic SQL ordering: `CASE queue_name WHEN 'high' THEN 0 WHEN 'default' THEN 1 ... ELSE 99 END ASC, priority DESC, run_at ASC`.
  - Worker lease timeouts (`locked_until`) are actively refreshed by worker background heartbeat intervals. If a worker process terminates abruptly or hangs, `recoverStaleJobs()` safely returns timed-out leases back to `pending` without manual intervention.
  - `QuietHoursGovernor` uses standard IANA timezones and `Intl.DateTimeFormat` to calculate next morning windows (default 09:00), shifting non-urgent patient-facing jobs without third-party cron packages.
