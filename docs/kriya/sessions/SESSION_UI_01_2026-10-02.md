- Light theme: DS §2.2 defines no light values for `--amber`, `--blue`, `--purple`, `--cyan`,
  `--border2`, `--shadow-lg`; `--border2` and `--shadow-lg` are derived (commented in `tokens.css`);
  amber/purple/cyan keep dark values and amber text on the light ground is below 4.5:1. Re-measure in
  WP-7.6 (04 §6 already asks for it).
- Existing inline styles still use the aliases; surfaces get the glass colour but not the blur until
  WP-7.3/7.4 apply `.glass`/the recipe per component.
- Aura is on `body` (covers shell + login) rather than only `.main` as DS §6.2 writes it.

## Decisions made
- Theme preference key `kriya-theme`, values `light`/`dark`; platform console ignores it (dark only).
- `--radius-sm` 3→8 px and `--radius-md` 6→10 px (DS small control / control radius), so existing
  components pick up DS radii without per-file edits.
