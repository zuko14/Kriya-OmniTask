## Decisions made / needed
- **D16 (Decision Trace & Observability Architecture)**:
  - Distributed execution traces are bound to workflow run correlation IDs (`id = run.id`).
  - Every node transition records an OpenTelemetry-compliant span with semantic attributes (`workflow.run.id`, `workflow.node.id`, `workflow.node.kind`, `workflow.step`, `workflow.action_tier`, `workflow.node.visit`, latency, tokens, cost).
  - Strict PII scrubbing (`PiiScrubber.redact`) runs automatically on all span inputs, outputs, and attributes before persistence.
  - `getDecisionTrace(runId)` reconstructs the full chronological timeline from checkpoints, state deltas, proof receipts, and verification jobs.
