## Decisions made / needed
- **D18 (Spend Protection, BYO Key Governance & Consolidated Model Gateway)**:
  - ModelGateway is the singular entry point for all model executions across the system.
  - Pre-call budget checks evaluate tenant monthly budget before dispatching any network request: 100% utilization or projected budget breach immediately refuses with `GatewayRefusedError`.
  - 95% utilization restricts executions to critical tasks (`isCritical: true`).
  - S31 tenant context boundary enforced: execution context must match request tenant, and vault access is gated by active tenant context.
  - Post-call settlement updates spend counters, detects 3x velocity anomalies (auto-pausing and creating Attention Items), and writes immutable `CostAttributionRecord` entries.
